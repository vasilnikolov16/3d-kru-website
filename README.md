# 3D KRU LAB

Информативен сайт за 3D KRU LAB — 3D печат и reverse engineering в Дупница.

## Локално

```bash
npm install
npm run dev
```

Сайтът се отваря на `http://localhost:5173`.

## Съдържание

- Проекти и материали: `src/data.js`
- Останалите текстове: `index.html`
- Снимки: `public/img`

## Публикуване

`main` държи изходния код, а `gh-pages` — готовия build (`npm run build` → `dist`), който GitHub Pages показва.
